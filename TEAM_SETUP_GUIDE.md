## ⏱️ First Time Setup (5 minutes - ONLY ONCE!)

### Step 1: Open the Leave Tracker
Go to: **https://cappasahebtuppa-godaddy.github.io/team-leave-tracker/**

### Step 2: Create GitHub Token (One Time Only!)

When you first open the app, you'll see a setup screen. Follow these simple steps:

1. **Click the link** in the popup that says "Create GitHub Token"
   - Or go directly to: https://github.com/settings/tokens/new?description=Leave%20Tracker&scopes=repo

2. **On the GitHub page:**
   - **Expiration:** Select **"No expiration"** ⚠️ IMPORTANT!
   - **Scope:** Make sure **"repo"** is checked ✅
   - Click the green **"Generate token"** button at the bottom

3. **Copy the token**
   - It starts with `ghp_`
   - Click the copy icon next to it

4. **Go back to the Leave Tracker**
   - Paste the token in the box
   - Click **"Save Token"**

5. **Done!** 🎉
   - Your token is saved in your browser
   - You'll NEVER need to do this again!

## ❓ FAQ

### Do I need to create a token every time?
**NO!** Only once. It's saved in your browser forever.

### What if I use a different browser?
You'll need to enter the token once in each browser/device you use.

### What if I clear my browser data?
You'll need to re-enter the token. Keep it saved somewhere safe!

### Can I see other people's changes?
Yes! Everyone sees the same data. Changes appear within 30 seconds.

### What if my token expires?
If you selected "No expiration", it won't expire. If it does, just create a new one and paste it in Settings.

### How do I delete a leave?
Click the red **"Delete"** button next to the leave.

## 🆘 Troubleshooting

### "Please configure your GitHub token in Settings"
- Click the ⚙️ Settings button
- Enter your GitHub token
- If you lost it, create a new one

### "Sync error" message
- Check your internet connection
- Try clicking 🔄 Refresh
- If still failing, your token might have expired - create a new one

### Changes not appearing
- Wait 30 seconds for auto-refresh
- Or click the 🔄 Refresh button
- Make sure you're connected to internet

### "Two team members are already on leave"
- This is by design! At least one person must be available
- Choose different dates or coordinate with teammates
